Ежедневная игра в слова: нужно угадать спрятанное слово, вводя другие. Каждая попытка получает номер — место в списке всех слов, отсортированном по смысловой близости к загаданному.

**1** — само загаданное слово, вы угадали. **2** — его ближайший сосед по смыслу. **8** — совсем рядом. **350** — тёплое направление. Дальше — мимо.

Близость смысловая, а не буквенная: к слову «зима» близки «мороз» и «декабрь», но не «зимбабве». Новая загадка каждый день в местную полночь.

Работает целиком в браузере, без сервера. Два языка на выбор, русский и английский.

## Как играть

Слово вводится в любой форме — игра сама приведёт его к начальной: «поезда» засчитается как «поезд», «cats» как «cat».

Кнопка «•••» рядом с полем открывает подсказку и «Сдаться». Подсказка выдаёт слово из тёплой зоны и стоит пять ходов, поэтому счётчик после неё прыгает с `#4` сразу на `#9`. Ближе десятого места подсказка не подходит — ответ она не выдаёт.

Стрелками в шапке можно вернуться к прошедшим дням. Прогресс и счётчик отгаданных хранятся в браузере; кнопка «Сброс» в подвале стирает всё.

## Запуск

Игра рассчитана на GitHub Pages. Локально, файлом с диска, она не заработает: браузер запрещает странице с `file://` подгружать соседние файлы.

1. Создать публичный репозиторий.
2. Загрузить в корень все пять файлов: `index.html`, `sw.js`, `slova.bin`, `ru.bin`, `en.bin`. Имена менять нельзя — игра ищет их по именам.
3. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
4. Через минуту-другую игра открывается по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

На айфоне стоит добавить её на домашний экран: «Поделиться» → «На экран „Домой"». Запускается на весь экран, без адресной строки.

`sw.js` необязателен. С ним игра после первого открытия работает без интернета: словари остаются в кэше браузера, страница подтягивается из сети и кэшируется на случай её отсутствия.

## Настройки

В начале `index.html` есть блок, который можно править обычным текстовым редактором:

```js
const CUSTOM = {
  title:      "Тепло",
  name:       { ru: "Бася", en: "Basya" },   // имя для приветствия
  winMessage: { ru: "Победа!", en: "Победа!" },
  extraRu:    [],    // свои слова для загадывания, например ["варенье"]
  extraEn:    []
};
```

Приветствие подставляется по времени суток и на языке игры: «Доброе утро, Бася» / «Good evening, Basya». Пустое имя — здоровается без обращения.

Слова из `extraRu` и `extraEn` добавляются к встроенным. Подойдёт почти любое обычное слово; если его нет в словаре, оно молча пропускается, а в консоли браузера появляется предупреждение.

## Как устроено

**Модели.** Русский — word2vec с [RusVectores](https://rusvectores.org/), обученный на Национальном корпусе русского языка; вектора лемматизированы и размечены по частям речи. Английский — [GloVe](https://nlp.stanford.edu/projects/glove/) на Wikipedia 2014 и Gigaword 5. Обе — 300 измерений.

**Хранение.** Вектора сжаты до одного байта на число. На 300 измерениях потери почти нулевые: средняя ошибка косинуса 0.0008, списки ближайших соседей совпадают с исходными float32 слово в слово. Файлы отдаются двоичными и распаковываются в браузере потоком через `DecompressionStream`.

**Словарь и ядро.** Догадка принимается по всему словарю: 38 000 русских лемм и 30 000 английских. А номер считается только по ядру ходовых слов — 15 000 и 12 000. Иначе редкий хвост раздувает ранги: слово «вода» от «винограда» получало 1620 вместо 653, потому что между ними втискивались полторы тысячи слов вроде «ступинский», которые никто никогда не введёт. Редкое слово при этом номер получает честный, оно просто меряется той же линейкой: «полустанок» стоит на 32-тысячном месте по частоте, а от «вокзала» получает 19.

**Морфология.** К русским леммам ведут 555 755 словоформ, собранных через [pymorphy3](https://github.com/no-plagiarism/pymorphy3). К английским — 45 236 форм через [LemmInflect](https://github.com/bjascob/LemmInflect), включая нерегулярные вроде `children → child`. Формы лежат одной отсортированной строкой, поиск делением пополам: объект на полмиллиона ключей браузер разворачивал бы в десятки мегабайт.

Английские формы сводятся осторожно — только множественное число и `-ed`. Иначе лемматизатор съедает самостоятельные слова: `painting` превращается в `paint`, `evening` в `even`, `number` в `numb`.

**Отбор загадок.** 628 русских и 800 английских. Слова отбирались по человеческим оценкам: [конкретность](http://crr.ugent.be/archives/1330) Брисбарта и [эмоциональная окраска](https://link.springer.com/article/10.3758/s13428-012-0314-x) Уорринера. Для русского таких наборов нет, поэтому оценка обучена на английских баллах и перенесена через кросс-язычное пространство [ConceptNet Numberbatch](https://github.com/commonsense/conceptnet-numberbatch): точность на отложенных словах 0.881 для конкретности и 0.838 для окраски. Абстракции вроде «отношения» отсеиваются — их мучительно угадывать, у них нет ясных соседей. Отдельно убраны анатомия, оружие и неприятное, а для русского ещё и уменьшительные, если основа уже в списке.

**Порядок.** Загадки перемешаны так, чтобы вчерашний ответ не подсказывал сегодняшний: слова разбиты на 16 смысловых групп, каждая разложена равномерно по всей длине, затем отдельный проход развёл оставшиеся близкие пары. Максимальная близость соседних дней — 0.41. Запаса хватает до мая 2028 года, дальше список идёт по кругу.

## Обновление

При замене файлов нужно поднять два номера, иначе браузер отдаст страницу из кэша:

- `CACHE` в первой строке `sw.js`;
- `BUILD` в начале `index.html`.

Текущий номер сборки виден в подвале игры справа, рядом со счётчиком сыгранных. Если после загрузки он не изменился, страница взята из кэша: Настройки → Приложения → Safari → Дополнения → Данные сайтов → удалить сайт. Прогресс при этом сотрётся.
